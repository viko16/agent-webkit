**CLI 和 IPC 的显式目标要求是破坏性变更。** 操作已有标签页时必须同时指定 Space 和 Tab。 即使 Space 只有一个标签页，也请传入 `--space SPACE --tab TAB_ID`，或在 IPC 的 `options` 中同时提供 `space` 和 `tab`。迁移脚本时，保存 `tab new` 返回的 `tabId`，也可以从 `tab list --space SPACE` 获取现有 ID。`tab default` 和对外的 `defaultTabId` 已移除；旧标签页关闭后，对其 ID 的操作会返回 `tab_not_found`。

- 观察窗口可以关闭当前页或其他页。⌘W 关闭当前页，⇧⌘W 隐藏窗口并保留后台服务。关闭当前页后优先选右邻页，GUI 选择独立于 Agent 目标。
- 手动关闭近期有 Agent 操作的页会请求确认，只读轮询和忙碌拒绝不延长五分钟保护期。操作可能中断下载或关闭待处理的网页对话框时，窗口会提示影响，并在确认后重检。
- Space 侧栏支持创建、休眠、恢复和删除。休眠保留 URL 和持久网站数据；删除会清除登录和网站数据，容器待清理时会明确显示。
